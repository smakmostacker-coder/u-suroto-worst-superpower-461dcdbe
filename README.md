An entry for the make.fun contest "Worst Superpower" — the most useless superpower in one line of at most 140 characters. The program `main.ts` (Node 22, standard library only, no network, no randomness) deterministically writes exactly one line to `/output/entry.txt`: the power to summon rain, but only indoors, only over the hero's own head, and only while already holding an umbrella.
